O PrevClima no seu celular.

Previsão local, mapa escuro de São Paulo e avisos para sua área. Acesse com sua conta de usuário.

Baixar para AndroidUsar no navegador

O APK é instalado diretamente, fora da Play Store. No iPhone, use a versão no navegador.

Como começar

  1. Baixe o aplicativo Android neste site e abra o arquivo no celular. Se o Android solicitar, permita a instalação por esse navegador para concluir.
  2. Crie sua conta de usuário e confirme o código recebido por e-mail.
  3. No perfil, escolha uma cidade e use o GPS para personalizar os avisos dentro de São Paulo.

É necessária conexão com a internet. Os avisos são consultados enquanto o aplicativo está aberto e visível; não há push com o aplicativo fechado. O som depende de uma interação anterior com a página.
