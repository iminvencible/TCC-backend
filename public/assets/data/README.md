# São Paulo boundary

`sao-paulo.geojson` is the IBGE state 35 boundary, downloaded on 2026-11-09
from https://servicodados.ibge.gov.br/api/v3/malhas/estados/35?formato=application/vnd.geo+json&qualidade=maxima .
It is shared by notification region checks and the map viewport mask. Coordinates
are GeoJSON longitude/latitude. It is a state boundary, not a weather forecast or
an estimate of storm motion.
